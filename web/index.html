Profil d’apprentissage

Conserve le nom pour mettre à jour ce modèle, ou saisis un autre modèle local pour le télécharger. Internet est nécessaire ; le téléchargement peut représenter plusieurs Go. Tes cours restent sur ce PC. Après le téléchargement, clique sur Enregistrer pour utiliser le modèle choisi.

Comptes liés à CyberMentor

Utilise ton compte ChatGPT via Codex ou ton compte Claude via Claude Code, sans clé API. Après la connexion officielle, tes questions, résumés et QCM restent dans cette interface.

Clique sur Vérifier les comptes.

La connexion s’effectue sur le site officiel. CyberMentor ne demande pas ton mot de passe. Il utilise les outils officiels du PC et conserve ici ses propres discussions ; les anciennes discussions des sites ChatGPT et Claude ne sont pas importées. Le modèle est celui choisi par défaut dans l’outil officiel.

Transfert manuel (facultatif)

Connecte-toi avec ton e-mail sur le site officiel du service. Aucune clé API nécessaire. CyberMentor ne reçoit ni ton mot de passe ni ta session de connexion.

Ouvrir ChatGPT ↗Ouvrir Claude ↗

Pour poursuivre ton apprentissage là-bas, prépare le contexte de ta discussion CyberMentor, copie-le puis colle-le dans une nouvelle discussion. Tu peux aussi y joindre toi-même le PDF du cours.

Ouverture du site et transfert manuel : les comptes ne sont pas liés automatiquement et les réponses restent sur le site choisi. Aucun cours n’est envoyé par ce bouton. Le partage commence lorsque tu colles et envoies le contexte dans ChatGPT ou Claude.

Quel modèle choisir ?

Utilise l’analyse du PC pour adapter le choix à ton matériel. Commence par le choix conseillé, puis compare les réponses sur un même cours.

Sélection vérifiée le 18 septembre 2026 dans le catalogue Ollama. Les tailles indiquent le téléchargement, pas la mémoire totale nécessaire. Le contexte et les autres applications consomment aussi de la mémoire. Ces modèles sont proposés à essayer, sans test de qualité sur tes cours à ce stade.

Mettre à jour un modèle conserve sa famille : pour passer de Qwen 2.5 à Qwen 3.5, sélectionne le nouveau modèle. Les futures sorties ne sont pas ajoutées automatiquement à cette sélection.
